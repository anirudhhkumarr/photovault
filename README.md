# PhotoVault 📸

**Private, lightweight photo library backed by your personal Google Drive.**

PhotoVault backs up, organizes, and protects your photos directly in your own Google Drive. It runs entirely in your browser with zero third-party servers, keeping your memories 100% private and in your control.

[**🚀 Open PhotoVault**](https://anirudhhkumarr.github.io/photovault)

---

## ✨ Features

- **🔒 100% Private & Client-Side:** No middleman servers or accounts to create. Everything stays in your browser and connects directly to your Google Drive.
- **☁️ Direct Google Drive Backup:** Photos are safely backed up to a dedicated `Photo Vault` folder in your personal Google Drive.
- **⚡ Smart Compression:** Dramatically reduces the storage space your photos take up while preserving crystal-clear image quality.
- **🔍 High-Definition Previews:** View full-screen photos and download your originals anytime with one click.
- **📁 Easy Uploads:** Drag and drop individual photos or entire folders to build your cloud library in seconds.
- **📱 Works Everywhere:** Fully responsive across desktop, tablet, and mobile browsers.

---

## 🚀 Quick Start

### Running Locally

```bash
# Clone the repository
git clone https://github.com/anirudhhkumarr/photovault.git
cd photovault

# Install dependencies
npm install

# Start the app
npm run dev
```

---

## 🔒 Privacy & Permissions

PhotoVault only requests access to create and manage its own files in your Google Drive (`Photo Vault` folder). It cannot see, read, or modify any other files in your Drive.
